# Order Management Policy

Policy ID: ORD-001
Version: 1.0

## Approved Order Total

The final approved order total represents the authorized
commercial value of an order before any separately approved
post-order adjustments.

Billing systems must use the approved order total when
creating an invoice unless an authorized adjustment exists.

## Order Changes

Any post-order adjustment must be recorded and associated
with the relevant order before billing.
